# Gift Market — Telegram Mini App demo

Демонстрационный каталог подарков для Telegram. Реальные покупки и переводы подарков не выполняются.

## Публикация
В репозитории откройте **Settings → Pages** и выберите источник **GitHub Actions**. После этого workflow автоматически опубликует сайт при обновлении ветки `main`.

## Подключение Telegram
После публикации скопируйте HTTPS-адрес сайта. В @BotFather выберите своего бота и настройте Menu Button / Web App, указав этот адрес.

## Ограничения демо
Предложения сохраняются в localStorage браузера на одном устройстве. Между разными пользователями они не синхронизируются; для настоящего обмена нужен сервер и база данных. Никакие реальные Telegram-подарки не перемещаются.
